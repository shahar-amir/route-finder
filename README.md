# Route Finder
A desktop application that finds the shortest route between two
points on a map, inspired by Waze.

## About
The project models a road network as a weighted graph and computes
the optimal path between any two nodes. Built as a personal project
to explore graph algorithms and their real world applications.

## Features
- Load a map and display it as an interactive graph
- Select a start point and a destination
- Compute the shortest route and highlight it on the map
- Display total distance and estimated travel time

## Algorithms
- **Dijkstra** for shortest path on a weighted graph
- **A\*** with a distance heuristic for faster search on large maps
